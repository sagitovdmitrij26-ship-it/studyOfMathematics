# Главная страница приложения в папке homePage

### папка homePage

```
1. advantages (блок с преимуществами тренажера)
    - **Advantages.css**  ( стили для этого блока)
    - **Advantages.js**   ( код блока. В блоке используем файл topic.json. В нем массив "advantages" для использования в карточках)
    - **AdvantagesCard.css** (стили для одной карточки в блоке)
    - **AdvantagesCard.js** (создание одной карточки)
2. entrance
3. hero
4. leaningPath
5. reviewsSection (блок с отзывами о тренажоре)
    - **reviewCard.js** (файл, содержит код создания одной карточки с отзывом. Взаимодействует с файлом review.json, и оттуда берет отзыв, автора, аватар. Также работает с файлом avatarImage и берет с него аварат автора пользователя. Также тут в массиве количество зверзд выводимое на карточку (рейтинг))
    - **reviewCard.css** (стили карточки одного отзыва)
    - **ReviewSection.js** (блок с отзывами, где есть шапка блока и футер с отзывами.)
    - **ReviewSection.css** (стили для всего блока с отзывами)
    - **ReviewsSlider.js** (файл для создания карусели с отзывами. Командой ***npm install swiper*** устанавливаем карусель. Затем подключаем файл в основной файл блока с отзывами. )
6. topicsSection
7. ctaSection (Call to Action - блок к призыву действиям на сайте.)
    -CtaSection.js (файл с кодом для соответствующего блока)  
                - div.initialConditions - первая строка с 1м предложением
                - div.inpBtn - строка для ввода и кнопка для создания аккаунта
                - div.pros - строка с плюсами начала работы с тренажером
    -CtaSection.css (стили для данного блока)
```

### папка components

```
1. header (шапка сайта с логотипом, названием, пункты навигации по сайту, кнопка входа и регистрации)
    -Header.css
    -Header.js
2. notification (компонент с различными вариантами уведомлений)
    -Notification.js (структура уведомления)
    -Notification.css (стили всплывающего уведомления, время показа и т.д.)
    -notificationVariants.js (содержится массив с различными вариантами уведомлений (иконки, текст))
3. icons (создадим компонент включающий все иконки сайта, чтобы потом их использовать в приложении, а не прописывать в компонентах пути каждой иконки)
4. logoSite (создадим компонент для основного логотипа и названия сайта. Логотип берем из компонента Icons)
    -Logo.js (Компонент с логотипом сайта чтобы подключать в разные компоненты при необходимости)
    -Logo.css (стили чтобы расположить название и логотип как нужно.)
5. footer. (Подвал сайта с различными блоками)
    -Footer.js
    -Footer.css
```
